# 042 — Блок «Похожие треки» под плеером: исполнитель и обложки

- **Дата:** 2026-10-26
- **Версии:** приложение 0.30.0 (`versionCode 31`)
- **Релиз с APK:** https://github.com/jappiy/BodroMusic/releases/tag/v0.30.0
- **Статус:** реализовано; сборка; на телефоне не проверено

## Задание

Пул задач 2026-10-26, п. 8: в «Похожих треках» у каждого трека только название и «В библиотеке» — добавить
исполнителя («Исполнитель · В библиотеке»); не показывается обложка, хотя она есть (Wonderful Life — Carrion: в меню
трека видна, в списке — заглушка).

## Что выяснено — причина

- Строка — общий `DiscoverTrackRow` (как в глобальном поиске): для трека из библиотеки подпись заменялась целиком на
  «В библиотеке», исполнитель терялся.
- Обложка бралась только из `coverUrl` источника (`RemoteImage`). Похожие приходят из bodrod `/tracks/similar`:
  Last.fm `track.getSimilar` картинок треков не отдаёт (или отдаёт пустые), у похожих по звучанию `coverUrl` нет вовсе.
  Меню трека открывается по `librarySongId` с настоящим `Song` из Navidrome — поэтому там обложка есть.

## Что сделано

- `DiscoverTrackRow`: трек из библиотеки — `CoverImage` по `mf-<id>` (Navidrome сам берёт вшитую обложку, затем
  обложку альбома), запасной вариант — `coverUrl`; подпись «Исполнитель · В библиотеке» (`similar_artist_in_library`).
  То же в поиске и популярных треках исполнителя.
- Чарты: позиция без обложки источника, но скачанная — обложка из библиотеки.
