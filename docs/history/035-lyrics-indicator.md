# 035 — Индикатор наличия текста песни

- **Дата:** 2026-10-26
- **Версии:** приложение 0.30.0 (`versionCode 31`)
- **Релиз с APK:** https://github.com/jappiy/BodroMusic/releases/tag/v0.30.0
- **Статус:** реализовано; unit-тесты и сборка; на телефоне не проверено

## Задание

Пул задач 2026-10-26, п. 1: нельзя понять, есть ли у трека текст, не открыв экран текста. Иконка текста в плеере
(панель повтора / перемешивания) должна явно различаться: «текст есть» (акцентная), «текста нет» (приглушённая или
перечёркнутая), «ищем» (без мигания). Проверять заранее — при загрузке трека и предзагрузке следующего. По
возможности — индикатор в списках треков (опционально).

## Что выяснено

- Текст запрашивался только при открытой панели (`PlayerViewModel.onLyricsVisible`), поэтому иконка не могла знать
  о наличии текста.

## Что сделано

- `data/repository/LyricsRepository.kt` (новый, синглтон): следит за `PlayerConnection.state`, при смене трека
  проверяет текущий трек и сразу за ним следующий в очереди; кэш 64 ответа по `учётка:трек`; ошибка сети не
  кэшируется (повтор при открытии панели). Состояние — `LyricsAvailability` (Loading / Missing / Available).
  Запускается из `MainViewModel` (сразу после старта приложения) и `PlayerViewModel`.
- `PlayerViewModel`: `lyricsAvailability` и прежний `lyrics` (для `LyricsSheet`) — из репозитория.
- `FullPlayerScreen.LyricsAction`: есть текст — акцентный цвет с подложкой; нет — 32 % яркости и диагональная черта;
  ищем — 55 % без черты, статично. `stateDescription` для TalkBack (available / missing / loading).
- Строки: `player_lyrics_available`, `player_lyrics_missing`, `player_lyrics_loading`.

## Что осталось / проверить

- Индикатор в списках треков не делался: для каждого трека списка нужен отдельный запрос `getLyricsBySongId`, это
  лишняя нагрузка и шум в строке. Можно добавить, если bodrod начнёт отдавать флаг наличия текста пачкой
  (у него есть `lyrics_status`).
- Проверить на телефоне три состояния иконки и что она меняется при листании треков.
