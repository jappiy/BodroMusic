# 032 — Мини-плеер скрыт на «Главной»

- **Дата:** 2026-10-24
- **Версии:** приложение 0.27.0 (`versionCode 28`)
- **Релиз с APK:** https://github.com/jappiy/BodroMusic/releases/tag/v0.27.0 (CI зелёный на `11efb42`, Release #21, APK в `dist`)
- **Статус:** реализовано; на телефоне не проверено

## Задание

На «Главной» не показывать нижний мини-плеер (обложка, название, лайк, назад/пауза/вперёд, полоса прогресса) — всё
это есть в волне, полноэкранный плеер открывается тапом по «таблетке». На остальных вкладках — как раньше. При
переключении вкладок появляется и исчезает плавно, отступы пересчитываются без прыжков.

## Что сделано

- `ui/app/BodroRoot.kt`: мини-плеер виден, если есть трек, плеер не развёрнут и текущий экран — не `HomeRoute`
  (экраны, открытые с главной, — исполнитель, альбом — мини-плеер показывают). Появление и скрытие — прозрачность и
  высота одновременно (`fadeIn + expandVertically`, 250 мс): нижняя панель `Scaffold` меняет высоту плавно, поэтому
  отступ содержимого пересчитывается без скачка и ничего не перекрывается.
