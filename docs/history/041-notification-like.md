# 041 — Явный лайк в уведомлении и на экране блокировки

- **Дата:** 2026-10-26
- **Версии:** приложение 0.30.0 (`versionCode 31`)
- **Релиз с APK:** https://github.com/jappiy/BodroMusic/releases/tag/v0.30.0
- **Статус:** реализовано; на телефоне владельца не проверено (телефон не был подключён по USB)

## Задание

Пул задач 2026-10-26, п. 7: в медиа-уведомлении / на экране блокировки лайкнутый трек — белая заливка сердца,
неочевидно. Сделать явно отличимым (красное сердце / обводка); на Android 13+ System UI перекрашивает иконки custom
actions в монохром — тогда другая форма. Проверить на телефоне; состояние — сразу после нажатия.

## Что выяснено

- Кнопки реакций — `CommandButton` в `setMediaButtonPreferences` с иконками `ICON_HEART_FILLED/UNFILLED` и своими
  `ic_heart_filled`/`ic_heart`. Android 13+ рисует медиаплеер в System UI и красит значки кнопок одним цветом
  (по палитре обложки), цвет из drawable игнорируется — разница только «залито / контур».
- Иконка менялась после `ReactionRepository.toggleLike` → смена `state` → `publishReaction` → `updateLayout`; это
  быстро, но после записи реакции.
- Виджета нет.

## Что сделано

- `res/drawable/ic_heart_liked.xml` (новый): залитое сердце с вырезанной галочкой (`evenOdd`), цвет `#E53935` — там,
  где оболочка цвет сохраняет (Android ≤ 12, часть оболочек), оно красное; где перекрашивает — отличается формой.
- `PlaybackService`: лайкнутое состояние — `ic_heart_liked`; по нажатию иконка меняется сразу (оптимистично), затем
  сохраняется реакция.

## Что осталось / проверить

- На телефоне владельца: уведомление и экран блокировки — видна ли галочка на 24 dp, перекрашивает ли оболочка
  (One UI / MIUI ведут себя по-разному). Если форма читается плохо — вариант крупнее: сердце с обводкой-ореолом.
