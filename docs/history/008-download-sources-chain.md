# 008 — Цепочка источников загрузки, Яндекс Музыка и YouTube Music

- **Дата:** 2026-10-19
- **Версии:** в работе
- **Статус:** в работе

## Задание

Сейчас bodrod ищет треки в slskd, а альбомы и артисты идут через Lidarr. Нужна единая настраиваемая цепочка
источников и два новых: Яндекс Музыка (API, FLAC) и YouTube Music (ytmusicapi + yt-dlp). Порядок по умолчанию:
Яндекс → slskd → YouTube Music → Lidarr. Цепочка одинаково работает для трека, альбома, добавления артиста в
отслеживаемые и загрузки по меткам; для каждой позиции — источники сверху вниз до первого успешного.

Подробно (сокращённо по пунктам владельца):
1. Общий интерфейс источника; порядок и флаг enabled в конфиге bodrod; отключённый/недоступный — пропуск с записью
   в лог; история попыток по каждому запросу; итоговый источник («Яндекс, FLAC») — в статусе заявки в приложении.
2. Яндекс: библиотека yandex-music (MarshalX) с `[crypto]` (encraw), токен в секретах; FLAC, иначе AAC 192;
   сопоставление «артист + название» с нормализацией и длительностью ±3 с; защита от превью (< 90 % длительности —
   удалить, неудача); альбомы и артисты — альбом целиком по ID; задержка 2–3 с между запросами; пропуск уже
   имеющегося; проверка Плюса при старте и раз в сутки (нет подписки → «недоступен» с причиной); теги и обложка
   из Яндекса, раскладка как у slskd.
3. Два переключателя: «Яндекс: скачивание» (выключить после конца подписки 20 ноября) и «Яндекс: метаданные»
   (поиск, теги, обложки, тексты; работает на бесплатном аккаунте). При включённых метаданных треки из slskd и
   YouTube перетегируются по Яндексу при уверенном совпадении.
4. YouTube Music: ytmusicapi (только «song»), yt-dlp bestaudio (opus/m4a) без перекодирования; длительность ±3 с,
   клипы/live/cover/remix отбрасывать, если их нет в запросе; прокси для yt-dlp; обновление yt-dlp; пометка lossy.
5. Lidarr — последний источник для альбомов и артистов (Soularr не меняется); туда — только ненайденное выше.
6. Экран «Источники загрузки» (админ): переключатели, порядок перетаскиванием, статус и причина; отдельно
   «Яндекс: метаданные».
7. Массовая выгрузка из Яндекса до 20 ноября: «Мне нравится», все мои плейлисты, полные дискографии выбранных
   артистов (список из лайков с отметкой «брать целиком»); низкий приоритет, задержки, возобновление после
   перезапуска, пропуск имеющегося, прогресс в приложении.

## Решения владельца

- «Загрузка по меткам» — это мониторинг в Lidarr: отслеживаемый артист → Lidarr помечает недостающие альбомы
  (wanted) → их пытаются скачать по всем каналам. Теперь эти альбомы тоже идут через цепочку bodrod.
