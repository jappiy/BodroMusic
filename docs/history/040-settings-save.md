# 040 — Настройки: размер кэша не сохраняется

- **Дата:** 2026-10-26
- **Версии:** приложение 0.30.0 (`versionCode 31`)
- **Релиз с APK:** https://github.com/jappiy/BodroMusic/releases/tag/v0.30.0
- **Статус:** реализовано; сборка; на телефоне не проверено

## Задание

Пул задач 2026-10-26, п. 6: у размера кэша нет «Сохранить», свайп «назад» теряет изменения. Добавить кнопку, при выходе
с несохранённым — сохранять или спрашивать; проверить остальные экраны настроек.

## Что выяснено

- Поле размера кэша сохраняло значение только по «Готово» на клавиатуре или при потере фокуса; при свайпе «назад»
  экран уходит из композиции без события потери фокуса — значение терялось.
- Вторая причина для всех экранов: `SettingsViewModel.update` писал DataStore в `viewModelScope`. Уход с экрана
  сразу после изменения очищает ViewModel и отменяет незавершённую запись.
- Остальные экраны: слайдеры сохраняют по `onValueChangeFinished`, диалоги (адреса учётки, привязка Яндекса) — по
  кнопке «Сохранить», чипы и переключатели — сразу. Другого «поля без сохранения» нет.

## Что сделано

- `SettingsViewModel.update` — в `AppScope` (запись переживает закрытие экрана) — для всех экранов настроек.
- «Воспроизведение»: значение поля поднято в экран; кнопка «Сохранить» (активна, если значение изменено и верно;
  иначе подпись «Сохранено»); выход кнопкой или свайпом «назад» (`BackHandler`) с изменённым верным значением
  сохраняет его; с неверным — диалог «Сохранить изменения?» («Не сохранять» / «Отмена»).

## Что осталось / проверить

- Размер кэша по-прежнему применяется после перезапуска приложения (подсказка под полем) — кэш создаётся один раз.
