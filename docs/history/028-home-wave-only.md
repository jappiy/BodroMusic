# 028 — Вкладка «Главная»: только волна

- **Дата:** 2026-10-24
- **Версии:** приложение 0.27.0 (`versionCode 28`)
- **Релиз с APK:** https://github.com/jappiy/BodroMusic/releases/tag/v0.27.0
- **Статус:** реализовано; снимки Robolectric (портрет, маленький экран, ландшафт, разложенный); на телефоне не проверено

## Задание

На «Главной» — только «Моя волна» на весь экран: шапка (настройки волны, заголовок или чип настроения, поиск),
имя исполнителя, обложка, play/pause, «таблетка» с лайком, короткий текст (028/029) и карусель настроений (030).
Всё, что было ниже, — на вкладку «Чарты» (031). Один визуальный стиль с фоном из 025, без подложек и секций с другим
фоном, без вертикальной прокрутки к другому контенту.

## Что сделано

- `ui/screens/home/HomeScreen.kt` — только `WaveHome` и лист настроек волны; `LazyColumn`, подборки и
  pull-to-refresh ушли на «Чарты». `HomeViewModel` — плеер, режимы, обложки исполнителей для аватаров,
  доп. информация трека (`TrackInfoRepository`).
- `WaveHome.kt`: экран на всю высоту на чёрном с `GlowBackground`; сверху шапка, по весам — блок трека, ниже —
  купола режимов. На экранах ниже 640 dp — компактный вариант (обложка 64 dp, имя до 44 sp). В ширину (ландшафт,
  разложенный) — исполнитель слева, управление справа; по высоте может не влезть — тогда блок волны прокручивается
  целиком (другого контента ниже нет).
- Лист настроек волны вынесен в `WaveSettingsSheet.kt`.

## Что осталось / проверить

- На телефоне: всё помещается без прокрутки на экране владельца, читаемость текста поверх свечения.
