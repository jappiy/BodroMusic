# 030 — Карусель настроений волны в стиле эталона («купола»)

- **Дата:** 2026-10-24
- **Версии:** приложение 0.27.0 (`versionCode 28`)
- **Релиз с APK:** https://github.com/jappiy/BodroMusic/releases/tag/v0.27.0
- **Статус:** реализовано; снимки Robolectric; на телефоне (ощущение свайпа) не проверено

## Задание

Вместо прямоугольных карточек с рамкой (и белой обводкой у выбранной) — как в `1792833948820_запись_2.mp4`: без
карточек, каждый элемент — сочный цветовой «купол» (арка со скруглённым верхом, насыщенный сверху, растворяется
книзу, мягкие края). Иконка (глиф настроения или аватар исполнителя) сверху наполовину заходит на купол. Подпись
белая жирная по центру, до 2 строк, над ней может быть серая категория («В стиле артиста»). Соседи немного
перекрываются, крайние уходят за край. Примагничивание к центру; центральный выше и крупнее, боковые ниже, меньше —
по пологой дуге, плавно во время свайпа. Выбранное — по центру + чип в шапке, без обводки. У каждого настроения свой
цвет и иконка.

## Что сделано

- `ui/screens/home/ModeDomes.kt`:
  - `ModeCard` — цвет купола, глиф, категория, аватар; цвета и глифы: Бодрое — оранжевый ⚡, Спокойное — голубой
    лист, Весёлое — жёлтый смайл, Грустное — индиго капля, Пошумим — красный динамик, Незнакомое — фиолетовый компас,
    Любимое — красное сердце, Популярное — малиновое пламя, Новое — зелёный, Без слов — фиолетовое пианино, На
    русском / английском — синий / красный, миксы — бирюзовый, розовый, золотой;
  - «В стиле: X» и «Новый релиз: X» с сервера — категория «В стиле артиста» / «Новый релиз», подпись — исполнитель
    (или альбом), круглый аватар — обложка исполнителя из библиотеки (`HomeViewModel.artistCovers`), нет —
    первая буква;
  - купол — путь со скруглённым верхом, вертикальный градиент «светлее сверху → цвет → прозрачно», блик у верха;
    под ним тот же силуэт шире с сильным размытием — ореол (размытие на Android 12+);
  - `LazyRow` с `rememberSnapFlingBehavior(SnapPosition.Center)`, отступы по краям = (ширина − купол) / 2,
    перекрытие −18 dp; в `graphicsLayer` по расстоянию до центра (в ширинах купола): масштаб −10 %, сдвиг вниз
    по параболе, прозрачность до −35 % — считается в фазе отрисовки, без перекомпоновки; центральный поверх соседей
    (`zIndex` по округлённому расстоянию);
  - тап — выбор режима и плавный перенос купола в центр; смена режима — карусель центрирует его; при выбранном
    режиме первым идёт «Назад к привычному» (серый купол).
- Число треков под режимом на куполе больше не пишется — в эталоне его нет.

## Решения

- Свайп карусели режим не переключает — только тап (как в эталоне), иначе листание запускало бы новые волны.

## Что осталось / проверить

- На телефоне: плавность дуги на свайпе, не мешает ли свайп куполов свайпу трека.
