# 047 — Главная: «В стиле артиста» без статики

- **Дата:** 2026-10-26
- **Версии:** приложение 0.31.0 (`versionCode 32`), bodrod 0.26.0 (фото исполнителей)
- **Релиз с APK:** https://github.com/jappiy/BodroMusic/releases/tag/v0.31.0
- **Статус:** реализовано; unit-тест правила; на телефоне не проверено

## Что выяснено — старое правило

Карточки «В стиле X» приходили из bodrod `GET /wave/modes` (`reco/wave.py: modes_for`): **топ-3 исполнителя за всё
время** по сумме «3 за каждый лайкнутый трек + ln(1 + прослушивания)» по отметкам Navidrome. Такие данные почти не
меняются — поэтому всегда Заточка & Pizza, System Of A Down, Noize MC. «3» вместо фото — это буква «З»: аватар искался
в библиотеке по точному имени «заточка & pizza», такого исполнителя в Navidrome нет, и рисовалась первая буква имени.

## Новое правило

- Первая карточка — исполнитель текущего трека; смена — с задержкой 1,5 с (быстрое пролистывание не дёргает
  карусель); ничего не играет — исполнитель последнего прослушанного трека.
- Вторая и третья — топ исполнителей за 14 дней по локальной истории (полное прослушивание 1, частичное ½, ранний
  пропуск 0), без первой; пара берётся из первых шести со сдвигом раз в 6 часов.
- Фото: исполнитель в Navidrome со своим фото → Deezer → Last.fm (bodrod `/images/artist`); имя «A & B» пробуется и
  целиком, и по основному исполнителю; заглушка — только если нигде нет.

## Что сделано

- `core/domain/wave/StyleArtists.kt` + `StyleArtistsTest`; `HistoryRepository.artistPlays / lastSong`;
  `HomeViewModel.styleCards`; `ModeDomes.withStyleCards` — свои карточки вместо серверных `artist:` на их месте,
  `ModeCard.avatarUrl`. Режим волны по-прежнему `artist:<имя>` (сервер понимает любое имя).
- Ограничение: история локальная — на новом телефоне топ пуст, тогда остаются карточки сервера.
