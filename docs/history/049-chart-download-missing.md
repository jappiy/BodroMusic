# 049 — Чарт: «Скачать недостающие»

- **Дата:** 2026-10-26
- **Версии:** приложение 0.31.0 (`versionCode 32`), bodrod 0.26.0 (пачка заявок)
- **Релиз с APK:** https://github.com/jappiy/BodroMusic/releases/tag/v0.31.0
- **Статус:** реализовано; на телефоне не проверено

## Что сделано

- `ChartScreens.kt`: под «Слушать» / «Можно слушать X из N» — «Скачать недостающие (N)» с подтверждением
  (сколько треков). Недостающие — `state == unavailable` и не «скачано, ждём скана» (упавшие ранее тоже).
- `ChartsRepository.downloadAll` — одна пачка `POST /requests/batch`, каждая позиция привязана к чарту; сервер не
  дублирует активные заявки и заново ставит упавшие. Строки сразу получают «в очереди», дальше чарт опрашивается
  каждые 10 с, пока что-то качается, — счётчик и статусы растут сами. Со старым bodrod — по одной заявке.
