# Задача 2. Discovery-пул и обратная связь

Новые треки сначала попадают в пул «на пробу», а в библиотеку их переводят только сигналы пользователя.

## Файлы
Пул лежит в `/volume2/music/_discovery/` и должен быть виден Navidrome (без `.ndignore`). Каждый трек хранится
одной физической копией, а привязка к пользователям ведётся в БД bodrod.

## Статусы
candidate → queued → downloading → in_pool → promoted | rejected | expired | failed.

## Правила (дефолты)
- **Размер пула:** 150 треков на пользователя. Пополнение раз в сутки, если осталось меньше 100.
- **Promote:** лайк, или два полных прослушивания (не меньше 80% длительности), или добавление в плейлист.
- **Reject:** дизлайк срабатывает сразу, скип раньше 30 секунд — на второй раз. Отклонённый трек попадает в чёрный
  список пользователя на 180 дней. Артист с тремя и более reject получает понижающий коэффициент.
- **Expire:** 21 день без прослушиваний или три показа в волне без запуска.
- **Удаление файла:** только если трек не держит другой пользователь или чарт.

## Promote технически
Файл переносится в основную библиотеку с тегированием bodrod. Нужно проверить, сохраняет ли текущая версия Navidrome
лайки и счётчики при переносе файла (persistent IDs). Если не сохраняет, bodrod после рескана переносит star и
playcount через Subsonic API.

## API bodrod
- `POST /feedback` принимает события: пользователь, song_id, событие (started / skipped / completed / liked /
  unliked / disliked), позиция, длительность, контекст (wave / chart / library / playlist), время.
- `GET /pool?user=` отдаёт пул пользователя.
- Метод «статус пула для списка id» — чтобы приложение могло помечать треки.

## Приложение
- События отправляются через офлайн-очередь.
- В плеере — кнопка дизлайка, как в Яндексе. Дизлайк трека из основной библиотеки исключает его из волны этого
  пользователя и понижает вес артиста. Файл при этом не трогается.
- Треки пула скрыты из артистов, альбомов и поиска. Видны только в волне, чартах и на экране «На пробу».
  В плеере у них метка «Новое».

## Моя волна
- Настройка характера: Любимое (0% пула), Микс (25%), Незнакомое (50%).
- Знакомая часть набирается текущей логикой весов.
- Два трека пула одного артиста подряд не ставятся.
