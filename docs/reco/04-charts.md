# Задача 4. Чарты

Чарты обновляются раз в сутки и выводятся на главной под «Моей волной».

## Источники в bodrod
- чарт Яндекса, пока доступен (потом скрывается);
- Deezer: мировой чарт и плейлист Top Russia;
- Last.fm: мировой чарт и `geo.getTopTracks` с `country=Russian Federation`;
- Apple Music RSS most-played для `ru`, если отдаёт;
- ListenBrainz: топ записей по всему сайту.

Хранится снимок с позицией и движением: вверх, вниз, новинка.

## Наличие треков
- Каждый трек чарта сопоставляется с библиотекой. Из топ-30 каждого включённого чарта (число настраивается)
  недостающие треки качаются в общий пул с владельцем «charts».
- Правила те же, что у пула: лайк любого пользователя переводит трек в promote. Если трек выпал из всех чартов и
  30 дней не слушался, он удаляется.
- API: `GET /charts` и `GET /charts/{id}`.

## Главная страница приложения
- Под «Моей волной» — раздел «Чарты»: горизонтальная лента карточек с коллажем обложек, названием и датой обновления.
- Экран чарта:
  - нумерованный список со стрелками движения;
  - у каждого трека состояние: в библиотеке / качается / недоступен (серым, по тапу «Скачать»);
  - кнопка «Слушать» играет доступные треки по порядку.
- В настройках выбираются чарты для главной и их порядок.
