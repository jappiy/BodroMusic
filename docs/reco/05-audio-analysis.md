# Задача 5. Анализ звучания

Отдельный воркер считает звуковые характеристики треков, а bodrod использует их для фильтра пула, настроения волны
и поиска похожих по звуку.

## Воркер
Отдельный Docker-контейнер на Python с essentia-tensorflow. Берёт задания у bodrod, читает файлы из смонтированной
библиотеки и отдаёт результат в bodrod. Где запускать, задаётся конфигом: на DSM с низким приоритетом или на ПК через SMB.

## Что считать
- Эмбеддинг discogs-effnet, а поверх него:
  - жанр (discogs400);
  - настроение (happy / sad / aggressive / relaxed);
  - danceability;
  - голос или инструментал.
- Плюс BPM, тональность и громкость.
- Модели Essentia распространяются под некоммерческой лицензией, для домашнего сервера это нормально.

## Очередь
Сначала новые треки пула и резерва, потом вся библиотека в фоне.

## Применение
- **Профиль вкуса.** У каждого пользователя 5–10 кластеров по эмбеддингам лайкнутых треков. Один центр не подходит:
  вкус многомодальный.
- **Фильтр пула.** Звуковая близость кандидата — максимальный косинус к центрам кластеров. Ниже порога трек в волну не
  попадает. При сильном отклонении он удаляется и снижает вес источника, который его предложил.
- **Моя волна.** Настроение (бодрое / спокойное / весёлое / грустное) выбирается по тегам. Переходы между треками
  сглаживаются по энергии и BPM.
- **Похожие по звучанию.** Пункт в меню трека: ближайшие соседи по библиотеке.
- **Хранилище векторов:** sqlite-vec или простой numpy-индекс, для домашней библиотеки этого хватит.
