# Задача 1. Архив Яндекс Музыки (два аккаунта)

До 20.11.2026 собрать с обоих аккаунтов всё, что потом пригодится движку рекомендаций, и предзакачать лучших кандидатов.

## Аккаунты
В секреты bodrod добавляются токены обоих аккаунтов, каждый привязан к своему пользователю Navidrome (владелец, жена).
Все данные хранятся отдельно по пользователю.

## Что собирать по каждому аккаунту
- Лайкнутые и дизлайкнутые треки, лайкнутые артисты и альбомы. Дизлайки сразу попадают в чёрный список этого пользователя.
- Похожие треки для каждого лайкнутого трека. Разовый проход с возможностью продолжить после обрыва.
- «Моя волна»: сэмплирование 2–3 раза в сутки в разных режимах.
  - Режимы перебираются по трём осям: характер (любимое / незнакомое / популярное), настроение
    (бодрое / весёлое / спокойное / грустное), язык (русский / иностранный).
  - За один прогон берётся несколько пачек подряд, последний трек пачки передаётся как queue.
  - Перед прогоном сохранить текущие настройки волны аккаунта и восстановить их после.
  - Фидбек скипов не отправлять, чтобы не портить живую волну.
- Похожие артисты для топ-200 артистов пользователя.
- Персональные плейлисты (Плейлист дня, Премьера, Дежавю, Тайник и т. п.): ежедневный снимок.
- История прослушиваний, если API её отдаёт.

## Общее (с одного аккаунта)
Чарт и новые релизы, ежедневно.

## Хранение
- Сырые JSON-ответы — в архив на volume2 по схеме `пользователь/дата/тип`.
- В БД bodrod — нормализованные таблицы:
  - треки: id, название, артисты, альбом, длительность;
  - рёбра «семя → кандидат»: тип (similar / wave / artist_similar / playlist), ранг, сколько раз встречалось, пользователь.

## Предзакачка, пока жива подписка
Лучшие кандидаты (по частоте в волне и в similar) качаются через Яндекс-источник в резерв `_reserve` с `.ndignore`.
Лимит 500 треков на пользователя. Позже пул пополняется из резерва без повторного поиска.

## Ограничения и окончание подписки
- Скорость около 1 запроса в секунду, бэкофф при ошибках, продолжение после обрыва.
- Когда подписка кончится, харвестер отключается сам при ошибках доступа.
- Всё, что продолжит отдаваться без Plus, собирать дальше.
- Архив остаётся источником `yandex_archive` для движка кандидатов.
